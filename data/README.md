# data/

Everything in this folder is generated by the scripts in `src/` and committed by the
daily GitHub Actions job. The website (`index.html`) reads these files directly.

| File | Written by | Contents |
|---|---|---|
| `cpi_data.csv` | `download_cpi.py` | Monthly CPI-U index (FRED `CPIAUCSL`) |
| `extra_series.csv` | `download_extra.py` | CPI components, average prices, wages, Fed funds rate, inflation expectations |
| `yoy_forecast.csv` | `arima_forecast.py` | 12-month forecast with 95% intervals |
| `forecast_archive.csv` | `archive_forecast.py` | Every published forecast, labelled by data vintage |
| `rolling_backtest.csv`, `backtest_errors.csv` | `rolling_backtest.py` | One-month-ahead backtest of nine ARIMA orders vs naive, and per-month errors |
| `horizon_backtest.csv` | `horizon_backtest.py` | Accuracy and 95% interval coverage for 1–12 months ahead |
| `model_benchmark.csv`, `model_benchmark_errors.csv` | `model_benchmark.py` | Naive vs ARIMA vs ARIMAX vs gradient boosting, with Diebold-Mariano tests |
| `social_preview.png` | `make_share_image.py` | Link preview image for social media |
| `cpi_release_schedule.csv` | maintained by hand | BLS CPI release dates (update yearly) |
